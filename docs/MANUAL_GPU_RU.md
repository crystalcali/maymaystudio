# Ручное подключение GPU к MayMay Studio

С 28.10.2026 режим по умолчанию — `COMPUTE_MODE=manual`. В «Мощностях» остались необязательная проверка баланса, подключение и управление приёмом заданий агентами, инструкции и рекомендации. Каталог, подбор цены, создание/сверка/удаление аренды и расчёт расхода локальных записей из UI убраны. Старые записи БД не удалены.

Studio не выполняет create/terminate в ручном режиме (API возвращает 410). Фоновое автозавершение старых инстансов и отмена задач по старым бюджетам отключены. Контроль lease, отмена процессов пользователем, загрузка результатов и очередь сохранены. Ответственность за завершение аренды — в панели YouGPU. Сбой API баланса не мешает подключению агента и выполнению задач.

## Один раз: образ GPU-окружения

1. GitHub → Actions → Build GPU agent → Run workflow. Дождитесь успешной сборки. Веса моделей не входят в образ.
2. Сделайте package `ghcr.io/crystalcali/maymaystudio-gpu` публичным. Выберите тег commit успешной сборки, а не произвольный SHA веб-деплоя.
3. В Timeweb задайте `AGENT_IMAGE=ghcr.io/crystalcali/maymaystudio-gpu:SHA_УСПЕШНОЙ_СБОРКИ`, `COMPUTE_MODE=manual`, проверьте HTTPS `PUBLIC_URL`, выполните redeploy.
4. HF read token и принятые лицензии нужны для моделей. YouGPU API key нужен только для кнопки проверки баланса. Без него ручной агент работает.

## Создать и подключить инстанс

1. В YouGPU вручную выберите одну NVIDIA GPU по таблице, достаточные RAM и рабочий SSD. SSH-ключ уже зарегистрирован; выбирайте его при создании.
2. Используйте Linux с Docker, NVIDIA driver и NVIDIA Container Toolkit. Не выбирайте CPU-only шаблон. Для CUDA 12.8 образа проверьте совместимость драйвера; наличие Docker само по себе не даёт контейнеру GPU.
3. Studio → Мощности → «Получить код и инструкцию». Код одноразовый, действует 15 минут.
4. Если провайдер поддерживает свой Docker image: вставьте образ из инструкции и переменные `STUDIO_URL`, `PAIRING_CODE`, `WORKER_NAME`. Оставьте стандартный CMD образа (`python -m agent.main`). Рабочий диск монтируется в `/workspace`. Получайте код непосредственно перед запуском; выделение железа/скачивание образа может занять больше 15 минут. Для уже подготовленного хоста удобнее следующий способ.
5. Если инстанс уже создан: на iPhone подключитесь через Termius по IP/пользователю из YouGPU и своему SSH-ключу. Скопируйте из модального окна Studio готовую `docker run` команду и вставьте в терминал. Она использует только GPU 0 и постоянный volume. Перед первым запуском выполните `nvidia-smi`; при ошибке исправьте драйвер/шаблон. Для Docker нужен root или пользователь с правами Docker.
6. Если ключ или код истёк, исправляйте подключение на том же инстансе. Не создавайте новую платную аренду.
7. В Studio дождитесь агента «Онлайн». Выберите его в генерации или форме обучения. Веса скачивает GPU-агент; ему нужен исходящий HTTPS к Studio, HF и S3.

Команда из UI не содержит YouGPU/HF токенов, только временный pairing code. Не публикуйте её в GitHub или чатах. Постоянные credentials агент сохраняет в `/workspace/maymay/worker.json`; не копируйте их между независимыми агентами.

Если окружение агента уже полностью установлено, можно запускать `python -m agent.main` с STUDIO_URL/PAIRING_CODE без Docker. Обычный Jupyter-образ не содержит автоматически всех зависимостей Studio; основной рекомендуемый путь — подготовленный Docker-образ. Не делайте `pip install -U torch` в рабочем контейнере.

## Проверить подключение и завершить работу

- `docker logs --tail 100 -f maymay-agent` — журнал. Если образ не найден: проверьте GHCR/tag/public. При GPU error проверьте драйвер и NVIDIA Container Toolkit. При registration 403 получите новый код; при сетевом timeout проверьте исходящий HTTPS с GPU-хоста к PUBLIC_URL.
- «Не брать новые» включает draining; уже запущенная задача продолжается.
- Начните с одного фото без LoRA; затем проверьте совместимый адаптер. Для Wan начните с короткого клипа. Скорость, качество и расход измеряйте на своём запуске.
- Отмените задания через Studio, дождитесь terminal и сохранения нужных файлов в S3. `docker stop maymay-agent` останавливает агент, но не оплачиваемый инстанс.
- Завершите аренду в YouGPU, убедитесь в TERMINATED и проверьте биллинг. Внешние диски могут оплачиваться отдельно. Автоматического завершения в Studio нет.

## Рекомендации по мощности

Это собственные ориентиры с запасом для первого запуска, **не измеренные минимумы**. На той же GPU более длинное видео/высокое разрешение/rank/batch/одновременные модели увеличивают память. Свободный SSD ниже не включает Docker-образ и исходный датасет; добавьте их объём отдельно.

| Пайплайн | VRAM одной GPU | RAM | Свободный SSD | Начальный режим |
|---|---:|---:|---:|---|
| Krea Turbo, фото | 48 GB | 64–96 GB | 150 GB | 1024, count 1; 24 GB с FP8/block swap — отдельный тест |
| Krea RAW, LoRA | 48–80 GB | 96–128 GB | 200 GB | Batch 1, rank16/32; offload при необходимости |
| Klein Base9B, фото/i2i | 48 GB | 64–96 GB | 150 GB | 50 steps, CFG4; 24 GB — с экономией памяти |
| Klein Base9B, LoRA | 48–80 GB | 96–128 GB | 200 GB | Batch1, checkpointing; 4 shards Qwen3 8B |
| Wan A14B, I2V/T2V | 80 GB | 128 GB | 250 GB | 832×480, 81 кадр; 48 GB — FP8/offload с проверкой |
| Wan A14B, LoRA I2V/T2V | 80 GB | 128 GB | 300 GB | 512 px,17 кадров,batch1; low/high последовательно |
| Wan TI2V5B, генерация | 48 GB | 64 GB | 150 GB | 1280×704,121 кадр;24 GB — пробовать CPU offload |
| Qwen2.5-VL3B captions | 16–24 GB | 32–64 GB | 60 GB | Один пример, BF16; видео по 8 кадрам |
| FFmpeg нарезка | CPU | 16 GB | По исходникам | CPU-агент, рецепт dataset.video |

Для фото ориентир RTX A6000 / RTX 6000 Ada 48 GB. Для тяжёлого Wan — A100/H100 80 GB. 4090 24 GB экономичнее по объёму памяти, но тяжёлые задачи требуют offload, и экономия аренды зависит от фактического времени. Цены и доступность смотрите непосредственно в YouGPU.

Текущие BF16-пайплайны не рассчитаны на T4/P100/V100. Одна задача работает на одной GPU: 2×24 GB не заменяют одну 48 GB. Несколько отдельных агентов могут выполнять независимые задачи. Увеличение block swap снижает VRAM, но требует RAM и замедляет передачи; FP8 может повлиять на качество. Wan5B LoRA в этой версии не включена.

Основания: Musubi описывает Krea inference с FP8/block swap на 24 GB; Klein Base9B использует отдельный Qwen3 8B encoder; для Wan возможны экономящие память режимы, но точные требования зависят от кадров/разрешения. Официальный Wan5B поддерживает потребительские GPU, однако инструкция upstream не гарантирует такой же пик памяти в нашем Diffusers-пайплайне. Поэтому таблица даёт запас.

## Разработчикам

`COMPUTE_MODE=legacy` оставлен только для совместимости старых API и регрессионных тестов. Новый UI не показывает аренду даже в legacy. Не включайте его для текущего ручного процесса. В tests/test_api.py исторический fixture теперь явно задаёт legacy, чтобы сохранить проверки прежнего контракта; отдельные тесты проверяют manual по умолчанию, запрет платных действий и сохранение контроля lease. Это намеренное изменение контракта, не отключение проверок.
